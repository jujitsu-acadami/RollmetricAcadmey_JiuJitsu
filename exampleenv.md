# Environment Variables

This application requires certain environment variables to be set to function correctly.

Create a `.env` file in the root of your project and add the following variables.

---

### Gemini API Key

This key is required to use the Google Gemini API for generating AI-powered feedback. You can obtain a key from Google AI Studio.

```
API_KEY="YOUR_GEMINI_API_KEY_HERE"
```

Replace `"YOUR_GEMINI_API_KEY_HERE"` with your actual API key.
